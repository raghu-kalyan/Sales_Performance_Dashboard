# 📊 Sales Performance Dashboard

## 📌 Project Overview

The **Sales Performance Dashboard** is an interactive data analytics project built using Excel and Power BI. It provides a comprehensive view of sales performance, profitability, and customer trends across different regions, categories, and time periods.

The dashboard helps in tracking key business metrics and enables data-driven decision-making through clear visualizations and insights.

---

## 🛠 Tools & Technologies

* Microsoft Excel (Data Cleaning & Preparation)
* Power BI (Data Visualization & Dashboard Creation)

---

## 📊 Key Features

* 📈 **KPI Metrics**

  * Total Sales: 341K
  * Total Quantity: 5239
  * Total Profit: 27K
  * Average Delivery Time: 4 Days

* 📅 **Time-Based Analysis**

  * Monthly Sales (Year-over-Year comparison)
  * Monthly Profit Trends
  * Sales trends by Year, Quarter, Month, and Day

* 🗂 **Category & Sub-Category Insights**

  * Sales by Category (Technology, Furniture, Office Supplies)
  * Top-performing Sub-Categories (Chairs, Binders, Phones)

* 🚚 **Shipping Analysis**

  * Sales distribution by Ship Mode (Standard, Second Class, First Class, Same Day)

* 🌍 **Regional Analysis**

  * State-wise sales and profit visualization using map charts

* 👥 **Customer Segmentation**

  * Consumer (48%), Corporate (33%), Home Office (20%)

* 💳 **Payment Mode Analysis**

  * COD (41%), Online (39%), Cards (20%)

---

## 🔍 Key Insights

* Consumer segment contributes the highest share of sales (~48%)
* Standard shipping mode dominates overall sales
* Certain states generate higher revenue, indicating regional performance differences
* Sales and profit show noticeable variation across months, highlighting seasonality trends
